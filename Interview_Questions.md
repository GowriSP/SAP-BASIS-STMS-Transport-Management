# SAP BASIS STMS Interview Questions

Q1. What is STMS?
Answer:
STMS is used for managing transports across SAP systems.

Q2. What is Domain Controller?
Answer:
The central system that manages transport configuration.

Q3. Difference between Consolidation and Delivery Route?
Answer:
Consolidation route transports changes from DEV.
Delivery route moves changes towards Production.

Q4. What is Transport Request?
Answer:
A container used to move SAP objects between systems.
